# RT อ่านสนุก ป.1
แหล่งเรียนรู้สำหรับครูสอนบนจอใหญ่ เปิดคำถามทีละข้อ แยก 8 หมวด กรองปี/รูปแบบ/ทักษะ พร้อมปากกา สี ยางลบ ย้อนกลับ สุ่มผู้ตอบ จัดกลุ่ม และดาวกิจกรรม

## ใช้งาน
เปิด index.html ผ่านเว็บเซิร์ฟเวอร์ HTTPS หรือ localhost ใช้ไฟล์แบบ ES modules เปิดผ่าน file:// ไม่ได้
รายชื่อและคะแนนบันทึกบนเครื่องก่อน เชื่อมบัญชีครู ป.1 เดิมเพื่อบันทึก Supabase แบบกดบันทึก
รองรับนำเข้า JSON คลังข้อสอบด้วยปุ่มข้อมูลข้อสอบ และส่งออกสำรองห้องเรียน/คะแนน CSV

## สถานะคลัง
643 กิจกรรม จากปี 2559–2568 รวมปี 2568 ทั้ง 3 รูปแบบ จัด 8 หมวด
เจ้าของอนุญาตให้เผยแพร่ข้อความ เฉลย และภาพต้นฉบับลง repository สาธารณะแล้ว
ไฟล์คำถามแยกตามปี/รูปแบบใน data/ ภาพ WebP เก็บในคลังหรือชุดภาพแยกตามหมวดใน data/asset-packs/ เพื่อโหลดเมื่อเปิดใช้
ปี 2562 อ่านออกเสียงอ้างฉบับกรรมการ ปี 2566 ไม่มีเฉลยอ่านรู้เรื่องยืนยัน ให้ครูตรวจเอง
หมวดย่อยใช้เป็นแนวช่วยค้นและให้ครูตรวจความเหมาะสมก่อนใช้
ไม่มีข้อมูลนักเรียนจริงในคลังที่เผยแพร่
คะแนนดาวเป็นคะแนนกิจกรรม ไม่ใช่คะแนนประเมิน RT ทางการ ข้อที่ไม่มีเฉลยยืนยันให้ครูประเมิน

## ฐานข้อมูล
db/rt-learning-classrooms.sql สร้างตารางแยก rt_classrooms เปิด RLS ให้เฉพาะครูที่ได้รับอนุมัติและเป็นเจ้าของห้อง
ใช้ publishable key ของโครงการเดิม ไม่มี service role key ฝั่งเว็บ บันทึกใช้ revision ตรวจการแก้ไขชนกัน

## ตรวจ
node tests.mjs ตรวจรายชื่อ เลขไทย เลขซ้ำ การมาเรียน กลุ่มสมดุล คะแนน และข้อมูลคลังไม่ถูกต้อง
