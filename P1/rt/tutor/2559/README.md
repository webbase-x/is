# แบบทดสอบ RT ป.1 ปีการศึกษา 2559 ฉบับข้อความ

จัดใหม่ **เฉพาะปี 2559** โดยคงองค์ประกอบของฉบับนักเรียนและลำดับหน้าเดิม (การอ่านรู้เรื่อง 6 หน้า + ปก / การอ่านออกเสียง 2 หน้า + ปก) แสดงหัวข้อ คำชี้แจง ข้อความโจทย์ บทอ่าน และตัวเลือกเป็น HTML text แทนการแสดงภาพแคปหน้าทั้งข้อ

- การอ่านรู้เรื่อง ตอนที่ 1: ข้อ 1–10 จับคู่คำกับภาพ (ภาพสีการ์ตูนกึ่งสมจริงจากไฟล์ assets ส่วนข้อความเป็น HTML), ข้อ 11–15 จับคู่ความหมายเป็นข้อความ
- ตอนที่ 2: ข้อ 16–21 ครบทุกข้อ บทอ่านคำถามและตัวเลือกเป็นข้อความ
- ตอนที่ 3: ข้อ 22–25 ครบทุกข้อ บทอ่านคำถามและตัวเลือกเป็นข้อความ
- การอ่านออกเสียง: ข้อ 1–20 สองคอลัมน์, ข้อ 21–26 ประโยค, ตอนที่ 3 ข้อความอ่านเต็ม
- แสดงเฉลยในโหมดครูเท่านั้น มีฟังก์ชันเก็บคำตอบบนเครื่อง พิมพ์ข้อสอบเต็มฉบับแยกสองส่วน
- ภาพจับคู่ข้อ 1–10 จำเป็นสำหรับข้อสอบ จึงคงภาพเดิมและตัดข้อความในภาพออกจากพื้นที่แสดง โดยวางคำเป็น HTML แยกต่างหาก
- คะแนนในเครื่องเป็นการฝึกใช้ ไม่ใช่ผลสอบ RT อย่างเป็นทางการ

ข้อความถอดและตรวจเทียบกับข้อสอบฉบับนักเรียน ปี 2559 ของสำนักทดสอบทางการศึกษา สพฐ. และไฟล์คลังเดิมใน repository

## ภาพสีการ์ตูนกึ่งสมจริงตามตัวอย่าง (อัปเดตล่าสุด)

คงลำดับเดิม เฉลยเดิม รวมภาพตัวเลือกหลอกลูกแพร์และเด็กกับช้าง ใช้ปุ่มและภาพแตะจับคู่ได้ ภาพถูกแสดงด้วยแท็ก img เพื่อพิมพ์ภาพสีได้โดยไม่พึ่ง background CSS

## เรียงศัพท์ตามข้อสอบและข้อความที่ผู้ใช้ให้ไว้

การแสดงคลังคำศัพท์เรียงตามตอนที่ปรากฏจริง: คำจับคู่ภาพ ๑–๑๐ → แสดงข้อความนิยามข้อ ๑๑–๑๕ และคำตัวเลือก ๗ คำตามลำดับ → คำอ่านออกเสียง ๑–๒๐ รวม ๓๗ คำ สามารถกรองตามหมวด/ค้นหาได้ เกมแฟลชการ์ดวางท้ายคลังและใช้งานร่วมกับรายการชุดเดียวกัน เลขข้อสองชุดเป็นคนละส่วนของข้อสอบ

## หนังสือภาพคำศัพท์ 10 คำ

คำจับคู่ภาพข้อ 1–10 ปรับจากรายการเฉลยเป็นหนังสือเปิดสองหน้า: ด้านซ้ายเป็นภาพสีที่จับคู่ตามเฉลยเดิม ด้านขวาเป็นคำศัพท์ที่ถูกป้ายแนวนอนปิดไว้ ผู้เรียนคลิกป้ายเพื่อพลิกเปิดดูคำ หรือพิมพ์คำตอบในช่องด้านล่างและกดตรวจ (รองรับ Enter) เมื่อพิมพ์ถูกต้องป้ายจะพลิกอัตโนมัติ พร้อมพลุสีและเสียงแสดงความยินดีด้วย Web Audio มีปุ่มปิดเสียงและโหมดลดการเคลื่อนไหวตามการตั้งค่าของเครื่อง

สามารถเปลี่ยนหน้า เลือกข้อ 1–10 ดูจำนวนคำที่ตอบถูก และเริ่มชุดใหม่ ผลที่ตอบถูกเก็บใน localStorage ของเครื่อง โดยคงแบบทดสอบและคลังข้อสอบต้นฉบับไม่เปลี่ยน คำตอบ 10 คำไม่แสดงล่วงหน้าในรายการคำศัพท์ (ต้องเปิดหนังสือหรือเล่นเกม) กลุ่มคำอื่นและแฟลชการ์ดเดิมยังอยู่ในแท็บเดียวกัน

## พลิกหน้ากระดาษ 3 มิติ

หนังสือคำจับคู่ภาพเปลี่ยนจากการหมุนกรอบทั้งเล่มเป็นกระดาษสองด้านที่พลิกหมุน 180° รอบสันกลาง มีด้านหน้า/หลังและเงาที่เคลื่อนตามมุมหน้ากระดาษ แอนิเมชันใช้กับปุ่มก่อนหน้า/ถัดไปและการเลือกข้อโดยตรง ป้องกันการกดซ้ำระหว่างพลิก รองรับมุมมองมือถือและ `prefers-reduced-motion` โดยยกเลิกแอนิเมชันเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว ไม่เปลี่ยนเนื้อหาคำศัพท์ คะแนน หรือการตรวจคำตอบ

## คำใบ้สลับตัวอักษร

ในหนังสือภาพ 10 คำ หน้าขวามีปุ่ม **คำใบ้ · เรียงตัวอักษร** โดยแผ่นคำใบ้ถูกซ่อนในครั้งแรก เมื่อคลิกจะแสดงตัวอักษรที่สลับตำแหน่งจากคำตอบ (คงเครื่องหมายภาษาไทยที่ผูกกับพยัญชนะ) นักเรียนแตะแผ่นตัวอักษรทีละอันเพื่อเติมลงช่องตอบได้ และมีปุ่มย้อนตัวล่าสุด/ล้างคำตอบ คลิกปุ่มอีกครั้งเพื่อซ่อนคำใบ้ เมื่อเปิดหน้าถัดไปหรือเลือกข้ออื่น คำใบ้จะซ่อนใหม่ทุกครั้ง เมื่อทำถูกจะแสดงเฉลยและเอฟเฟกต์เดิม โดยไม่ได้เปลี่ยนคำศัพท์หรือเฉลยต้นฉบับ

## ขยายหนังสือเต็มจอ

เพิ่มปุ่ม **⛶ เต็มจอ** ในแถบเครื่องมือหนังสือ กดเพื่อขยายหนังสือใช้พื้นที่หน้าจอทั้งหมด พร้อมปุ่ม **⤢ ย่อหน้าจอ** เพื่อกลับมุมมองเดิม ใช้ `Element.requestFullscreen()` เมื่อเบราว์เซอร์รองรับ; หากไม่รองรับหรือปฏิเสธ เช่น iPhone/iPad บางรุ่น ใช้ overlay ตรึงเต็ม viewport แทน รองรับ Escape เพื่อปิด overlay และคืนตำแหน่ง scroll เดิม CSS ปรับขนาดหน้าหนังสือ ภาพ ฟอร์ม และแถบเลื่อนหน้าให้เหมาะกับทั้งคอมพิวเตอร์และมือถือ โดยไม่เปลี่ยนคำศัพท์หรือความคืบหน้าในเกม

## อัปเกรดภาพสีสดใสความละเอียดสูง

เปลี่ยนชุดภาพแสดงผลปี 2559 เป็น `assets/pictures-2559-vivid-hd.webp` ซึ่งเป็นภาพการ์ตูนกึ่งสมจริงสีสดจำนวน 12 รูป เรียงตามต้นฉบับ โดยแผ่นภาพมีขนาดจริง 576×2880 พิกเซล (แต่ละรูป 576×240) จากเดิม 144×720 (แต่ละรูป 144×60) จึงเพิ่มจำนวนพิกเซล 16 เท่าและโหลดเป็น WebP ขนาดประมาณ 103KB ไฟล์เดิมเก็บไว้เพื่อสำรอง หน้าแบบทดสอบ หนังสือภาพเต็มจอ และเกมแฟลชการ์ดอ้างอิงภาพใหม่ทั้งหมด และคงลำดับคำตอบเดิมทุกข้อ

`width/height/rowHeight` ใน `color-pictures.js` ยังเป็นขนาดตรรกะสำหรับคลิปสไปรต์เดิมที่มีขนาด CSS 180×900 พิกเซล ส่วน `sourceWidth/sourceHeight` ระบุความละเอียดไฟล์จริง เพื่อไม่ให้ภาพในแบบทดสอบหรือเกมปรากฏผิดตำแหน่ง

## หน้าปกหนังสือภาพ เล่ม ๑

เพิ่มภาพหน้าปกสีการ์ตูนกึ่งสมจริงใน `assets/rt2559-book-cover-volume-1.webp` หนังสือจะแสดงแบบ **ปิดเล่มเมื่อเข้าครั้งแรก** ผู้เรียนแตะภาพปกหรือปุ่ม **เปิดหนังสือ** จึงจะเห็นเนื้อหา เปิดพร้อมการหมุนปก 3 มิติ (หากตั้งค่า reduced motion จะเปิดทันที) และมีปุ่ม **ปิดหนังสือ** ในแถบเครื่องมือเพื่อกลับหน้าปก ป้ายบนภาพเป็นตัวอักษร HTML เพื่อคมชัดและตรงตามอักขรวิธี: **หนังสือภาพทายคำ**, **เล่ม ๑**, **RT ปี ๒๕๕๙**, **ผู้ผลิตหนังสือ: ครูไพรัช อินควรชุม**; ใช้เลขไทยในข้อความส่วนเกมและคลังคำศัพท์ โดยไม่เปลี่ยนรหัส/URL/เฉลยต้นฉบับ

อัปเดตตัวเลขที่แสดงในหน้ารวม Tutor หน้าแบบทดสอบ คลังคำศัพท์และคะแนนให้เป็นเลขไทยทั้งหมด รวมข้อความสำหรับผู้ช่วยอ่านหน้าจอ โดยไม่เปลี่ยนค่าเชิงข้อมูลของปี/เลขข้อที่ใช้ภายในระบบ


## ปกเล่ม ๑ ฉบับแก้ไข
เปลี่ยนภาพเป็น `assets/rt2559-book-cover-volume-1-revised.webp` และนำข้อความ HTML ซ้อนทับออกเพราะข้อความไทยทั้งหมดอยู่ในภาพแล้ว (รวมชื่อ **ครูไพรัช  อินควรชุม**) การเปิด/ปิดหนังสือ ระบบคำใบ้ คะแนน และพลุยังเหมือนเดิม

## เล่ม ๑ · นำเข้าการอ่านออกเสียงคำ ๒๐ คำ

หลังบทคำจับคู่ภาพ ๑๐ ข้อ หนังสือพลิกหน้า 3 มิติเล่มเดียวกันต่อด้วย **ตอนที่ ๒ การอ่านออกเสียงคำ ข้อ ๑–๒๐** นำคำจาก `data.json` ตามลำดับเดิมครบถ้วน ตั้งแต่ ปูเสื่อ ถึง เดี๋ยวนี้ รวม ๓๐ หน้าคำศัพท์ ไม่เปลี่ยนเนื้อหาต้นฉบับ

ผู้เรียนเห็นคำไทยตัวใหญ่ด้านซ้ายของหนังสือ ด้านขวาเป็นคำแนะนำฝึกอ่านและปุ่ม **อ่านได้แล้ว** / **ฝึกอีกครั้ง** กดบันทึกผลด้วยตนเองเท่านั้น ไม่อ้างว่าระบบตรวจเสียงจริง ผลจะสัมพันธ์กับความคืบหน้าในคลังและแฟลชการ์ดผ่าน localStorage การกด **เริ่มใหม่** ล้างทั้งผลจับคู่ภาพและผลฝึกอ่าน สารบัญแยกตอนให้เปิดข้อที่ ๑ ของแต่ละตอนอย่างรวดเร็ว พร้อมตัวเลขข้อไทยบนปุ่มเปลี่ยนหน้า ส่วนหน้าปกและโหมดเต็มจอคงเดิม

## เปิดบทอ่านออกเสียงจากหน้าปก (๒๐ คำ)

บนปกของหนังสือเล่ม ๑ มีทางเข้าสองปุ่มอย่างชัดเจน: **เปิดตอนที่ ๑ · จับคู่ภาพ** และ **เปิดตอนที่ ๒ · อ่านออกเสียง** กดปุ่มหลังแล้วเปิดหน้าคำว่า **ปูเสื่อ** โดยตรง (หน้า ๑๑ จาก ๓๐ หน้าภายในเล่ม) นอกจากนี้คลิกหมวด **คำอ่านออกเสียง (๒๐)** ในคลังจะเปิดตอนที่ ๒ ในหนังสือเดียวกันแทนแสดงรายการแยกด้านล่าง รองรับลิงก์ `?book=oral#vocab` เพื่อเปิดบทอ่านออกเสียงโดยตรง และเพิ่มเวอร์ชันใน URL โหลดไฟล์ JavaScript/CSS เพื่อหลีกเลี่ยงแคชของเบราว์เซอร์หลังอัปเดต

## ปรับเลขหน้าให้ต่อเนื่องในเล่ม ๑

คำจับคู่ภาพแสดงลำดับ ๑–๑๐ และคำอ่านออกเสียงต่อด้วยลำดับ **๑๑–๓๐** ในปุ่มเลือกคำและข้อความบนหน้า เช่น ปูเสื่อ = คำ ๑๑, เดี๋ยวนี้ = คำ ๓๐ โดยยังเก็บหมายเลขข้อสอบอ่านออกเสียงต้นฉบับ ๑–๒๐ แยกจากเลขลำดับในเล่ม ไม่แก้ข้อความจากต้นฉบับ และปรับพารามิเตอร์เวอร์ชันของไฟล์โมดูลเพื่อไม่ให้โหลดโค้ดเก่าจากแคช

## แสดงคำ ๑๑–๓๐ ภายในหนังสือจริง

แก้สาเหตุที่เลือกหมวดคำจับคู่ภาพ (๑๐) แล้ว `setCards` ถูกกรองเหลือเพียง ๑๐ หน้า: ปัจจุบันการเลือกหมวดในคลังเปลี่ยนเฉพาะ **ตอนที่เปิด** โดยหนังสือยังมีคำครบ ๓๐ เสมอ (ยกเว้นผู้ใช้ค้นหาด้วยข้อความ) กดถัดไปจากหน้า ๑๐ จะไปหน้า ๑๑ `ปูเสื่อ` ได้ทันที แถบเลือกเลขหน้าจะแสดงทั้งสองหมวดพร้อมกัน ๑–๑๐ และ ๑๑–๓๐ เลื่อนแถบเลขในแนวนอนบนโทรศัพท์เพื่อเลือกได้ทุกคำ แท็บคำอ่านออกเสียงยังเปิดหน้าที่ ๑๑ ได้โดยตรง

## รูปแบบเกมเดียวกันทุกคำ ๑–๓๐

ปรับทั้งหนังสือให้เป็นรูปแบบ **ดูภาพด้านซ้าย → ป้ายปิดคำด้านขวา → พิมพ์คำตอบหรือเปิดคำใบ้ตัวอักษรสลับ → ตรวจคำตอบ → ป้ายพลิกพร้อมพลุและเสียง** สำหรับคำทั้ง ๓๐ คำ รวมทั้งคำอ่านออกเสียงเดิม ๒๐ คำ ด้านซ้ายของตอนที่ ๒ แสดงภาพแนวคิดให้เด็กเดาคำ (มีภาพสัญลักษณ์ประกอบแบบออฟไลน์) โดยไม่มีตัวคำเฉลยล่วงหน้า ผลตอบถูกบันทึกในเบราว์เซอร์เช่นเดียวกับคำ ๑–๑๐ และคงเลขหน้าไทย ๑–๓๐

## ภาพต้นฉบับคำที่ ๑๑–๓๐ (อัปเดต ๒๔ พ.ย. ๒๕๖๙)

แสดงภาพจากต้นฉบับที่ผู้ใช้แนบมาโดยตรงในรูปแบบ JPEG ต้นฉบับ ๑๑๒๒×๑๔๐๒ พิกเซล (๔ คอลัมน์ × ๕ แถว) ข้อมูลภาพอยู่ใน `assets/pictures-2559-oral20-user.jpeg` และแมปแถว/คอลัมน์ตามลำดับคำศัพท์จาก `data.json` ข้อที่ ๑๑–๓๐ โดยไม่มีการใช้รูป Emoji ทดแทน ไม่แก้คำตอบหรือระบบตรวจคำตอบ ป้ายเปิดเฉลย คำใบ้ และเอฟเฟกต์เหมือนข้อที่ ๑–๑๐ ตรวจความถูกต้องของภาพจาก SHA-256 ของไฟล์ที่แนบมาโดยตรง
