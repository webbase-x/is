# RT Tutor · แบบทดสอบประเภทที่ 1 (ฉบับข้อความ)

หน้าแยกใหม่ของ RT อ่านสนุก ป.1 ใช้งานที่ /P1/rt/tutor/ โดย **ไม่แก้ ไม่ย้าย และไม่ลบระบบ RT เดิม** ที่ /P1/rt/

- แสดง **รูปแบบที่ 1** จากไฟล์ต้นฉบับ \`../data/<ปี>-1.json\` ปี 2559–2568
- แบ่งข้อทดสอบอ่านออกเสียงเป็น **อ่านคำ / อ่านประโยค / อ่านเรื่อง** พร้อมกรองปีและหมวด
- แสดง **ข้อความจริง** จาก \`prompt\` และไม่สร้างข้อความ/เฉลยแทนข้อที่เป็นภาพ
- ไม่รวมข้อสอบอ่านรู้เรื่องและเขียนจากภาพในเวอร์ชันข้อความนี้ ข้อเหล่านั้นยังเปิดใน /P1/rt/ ตามเดิม
- ครูฟังนักเรียนอ่านแล้วบันทึกคะแนน 0–คะแนนเต็มของแต่ละข้อ (ไม่มีระบบรู้จำเสียง/ให้คะแนนอัตโนมัติ)
- จดคะแนนไว้ใน localStorage ของเบราว์เซอร์ แยกตามปี; สรุปผลและส่งออก CSV ได้; ไม่ส่งชื่อ/คะแนนขึ้นฐานข้อมูล
- ค่าคะแนนเป็นคะแนนฝึกอ่าน ไม่ใช่คะแนนประเมิน RT อย่างเป็นทางการ

## การทดสอบ

จากโฟลเดอร์ \`P1/rt/\` รัน \`node tutor/tests.mjs\` เพื่อตรวจคลังทุกปี การคัดข้อที่เป็นข้อความ การป้องกันข้อมูลต้นฉบับถูกแก้ การคำนวณคะแนน และ CSV

> รูปแบบที่ 2 และ 3 ยังไม่เปิดในหน้า tutor นี้ เพื่อให้ดำเนินการเฉพาะประเภทที่ 1 ก่อน
