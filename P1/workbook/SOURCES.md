Each unique worksheet is mapped to one gamified activity. All 150 worksheet pages are explicitly tagged in `book.json` with `gamified: true` and an `activityType`. Non-handwriting pages no longer use free drawing or typed completion; they are transformed into listening-choice, word-building, sentence-order, quiz, or page-specific interactive games. The final worksheet page of each chapter is tagged `handwriting` and is rebuilt as a touch/stylus tracing activity using the original source text where the scanned source is available. Unit 11–12 source image placeholders are empty in this repository, so their handwriting model falls back to the chapter lesson text rather than fabricating a scan. Progress remains device-local and scoped to the current student/teacher selection. Correct game completion or handwriting threshold unlocks the next activity, followed by the existing review and game.
