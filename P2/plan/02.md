## 1. มาตรฐานการเรียนรู้ / ตัวชี้วัด

- มฐ. ท 1.1 ใช้กระบวนการอ่านสร้างความรู้และความคิดเพื่อนำไปใช้ตัดสินใจ แก้ปัญหาในการดำเนินชีวิต และมีนิสัยรักการอ่าน
- มฐ. ท 4.1 เข้าใจธรรมชาติของภาษาและหลักภาษาไทย การเปลี่ยนแปลงของภาษาและพลังของภาษา ภูมิปัญญาทางภาษา และรักษาภาษาไทยไว้เป็นสมบัติของชาติ
- ท 1.1 ป.2/1 อ่านออกเสียงคำ คำคล้องจอง ข้อความ และบทร้อยกรองง่าย ๆ ได้ถูกต้อง
- ท 1.1 ป.2/2 อธิบายความหมายของคำและข้อความที่อ่าน
- ท 4.1 ป.2/2 เขียนสะกดคำและบอกความหมายของคำ
- ท 4.1 ป.2/3 เรียบเรียงคำเป็นประโยคได้ตรงตามเจตนาของการสื่อสาร

## 2. สาระสำคัญ / ความคิดรวบยอด

มาตราแม่กง คือ คำที่มีพยัญชนะ "ง" เป็นตัวสะกด เมื่ออ่านออกเสียงจะมีเสียงพยัญชนะ /ง/ อยู่ท้ายคำ การเรียนรู้ผ่าน Web Application เกมมิฟิเคชัน เป็นสื่อหลัก จะช่วยให้นักเรียนสามารถสังเกต เปรียบเทียบ และบอกความแตกต่างระหว่างคำในมาตราแม่กงกับคำในมาตราอื่น ๆ ได้ และสามารถนำคำมาตราแม่กงไปเลือกใช้หรือเรียงเป็นประโยคเพื่อการสื่อสารได้อย่างถูกต้อง

## 3. จุดประสงค์การเรียนรู้

- **K (ความรู้):** นักเรียนบอกความหมายและลักษณะของคำในมาตราแม่กงได้ถูกต้อง
- **P (ทักษะกระบวนการ):** นักเรียนอ่านออกเสียง จำแนกคำ และเลือกคำมาตราแม่กงมาเรียงเป็นประโยคได้ถูกต้องผ่านภารกิจใน Web Application
- **A (เจตคติ):** นักเรียนกล้าคิด กล้าตอบ ให้ความร่วมมือในการทำงานกลุ่ม และมีความกระตือรือร้นในการเล่นเกมอย่างต่อเนื่องตลอดคาบเรียน

## 4. สาระการเรียนรู้

- ความหมายและลักษณะของมาตราแม่กง (คำที่มี ง เป็นตัวสะกด)
- การอ่านออกเสียงและจำแนกคำมาตราแม่กง
- การเลือกคำและเรียงคำมาตราแม่กงให้เป็นประโยค
- ตัวอย่างคำมาตราแม่กงที่ใช้ในกิจกรรม: กอง คาง กำแพง กิ่ง เข่ง โค้ง งวง แซง ทุ่ง ธง นิ่ง ผึ้ง รัง แรง วง ส่อง กางเกง ดัง มอง ทาง ช้าง
- ตัวอย่างคำมาตราอื่น (ใช้เปรียบเทียบ): กา, ปู, นก, ขนม, กุหลาบ

## 5. สมรรถนะสำคัญของผู้เรียน

- **ความสามารถในการสื่อสาร:** การอ่านออกเสียงคำ ตอบคำถาม และการสื่อสารผ่านประโยค
- **ความสามารถในการคิด:** การสังเกต วิเคราะห์ จำแนกคำ และการเรียบเรียงความคิดเป็นประโยค
- **ความสามารถในการใช้เทคโนโลยี:** การใช้งาน Web Application เพื่อทำภารกิจและเล่นเกมผ่านหน้าจออุปกรณ์ส่วนตัว

## 6. คุณลักษณะอันพึงประสงค์

มีวินัย, ใฝ่เรียนรู้, มุ่งมั่นในการทำงาน

## 7. ชิ้นงานหรือภาระงาน

- คะแนนและเหรียญรางวัล (Point / Badge) จากการเล่นเกมบน Web Application (ชิ้นงานหลัก)
- กระดาษประโยค "แกลเลอรี่ประโยคแม่กง" ของแต่ละกลุ่ม
- Exit Ticket (แบบทดสอบท้ายบทเรียนผ่าน Web Application)
- ใบงานที่ 2 เรื่อง มาตราแม่กง

## 8. กิจกรรมการเรียนรู้ (Gamification Web Application เป็นสื่อหลัก ร่วมกับ Active Learning)

> **หมายเหตุ:** ครูตรวจสอบอุปกรณ์ สัญญาณอินเทอร์เน็ต และล็อกอินเข้า Web Application ของนักเรียนทุกคนให้พร้อมก่อนเริ่มคาบเรียน โดยสื่อทั้งหมดจะถูกนำเสนอผ่านโปรเจกเตอร์ด้วยแอปพลิเคชันตัวเดียวกันนี้

### ขั้นที่ 1 กระตุ้นความสนใจและเตรียมความพร้อม (5 นาที)

1.1 ครูฉายรหัสห้องเรียน (Room Code) ขึ้นบนโปรเจกเตอร์ ให้นักเรียนกรอกรหัสและตรวจสอบหน้าจอ Teacher Dashboard

1.2 ครูเปิดสื่อมัลติมีเดียอุ่นเครื่อง "ร้องเพลงคาราโอเกะ แม่กง" บนหน้าจออุปกรณ์ของนักเรียนสั้น ๆ เพื่อนำเข้าสู่บทเรียน (ไม่เก็บคะแนน) เนื้อเพลงไล่คำขึ้นบนหน้าจอ (เช่น ธง, คาง, ผึ้ง ปนกับคำมาตราอื่น เช่น ปู, นก) ให้นักเรียนร้องตามและแตะคำที่เป็นแม่กง พร้อมตั้งคำถามกระตุ้นคิด "คำว่า ธง, คาง, ผึ้ง มีจุดเด่นอะไรที่เหมือนกันที่พยัญชนะตัวสุดท้าย"

### ขั้นที่ 2 เชื่อมโยงความรู้เดิมและเตรียมพร้อมเข้าเกม (5 นาที)

2.1 ครูฉายคำศัพท์ผ่านหน้าจอ Web Application ขึ้นบนโปรเจกเตอร์ (ผสมคำแม่กง เช่น กำแพง, กางเกง, รัง กับคำมาตราอื่น เช่น ขนม, กุหลาบ) ให้นักเรียนช่วยกันอ่านออกเสียงและบอกความหมายของคำสั้น ๆ

2.2 ครูให้เหตุผลสั้น ๆ ทุกครั้ง เช่น "รัง อ่านออกเสียง รอ-อะ-งอ รัง มี ง เป็นพยัญชนะท้ายคำ จึงเป็นแม่กง" แล้วสรุปว่า "คำที่มี ง เป็นตัวสะกด เรียกว่า มาตราแม่กง"

2.3 ครูอธิบายกติกาการเล่นเกมบนหน้าจอ พร้อมสาธิตตัวอย่าง 1 รอบ

### ขั้นที่ 3 ลงมือเล่นเกมบน Web Application (25 นาที) — กิจกรรมหลักของแผนการสอน

3.1 **ภารกิจ "กล่องคำแม่กง"** (ด่านจำแนกคำ): บนหน้าจออุปกรณ์ของนักเรียนจะแสดงสายพานที่มีคำศัพท์ไหลผ่านทีละคำ (ผสมคำแม่กง เช่น กอง, กิ่ง, เข่ง, โค้ง, งวง, ทุ่ง กับคำมาตราอื่น) ให้นักเรียนลากเฉพาะคำที่เป็น "มาตราแม่กง" ลงกล่องแม่กงให้ทันเวลา ลากถูกได้คะแนน ลากผิดระบบสั่นเตือน

3.2 **ภารกิจ "จรวดประโยคพุ่งทะยาน"** (ด่านเรียงประโยค): บนหน้าจอแสดงคำศัพท์ที่สลับตำแหน่งกันอยู่ ให้นักเรียนเลือกลากคำศัพท์มาต่อกันเป็นท่อนเชื้อเพลิงเรียงซ้อนขึ้นลำจรวดให้เป็นประโยคที่สมบูรณ์และมีความหมายถูกต้อง (เช่น ลากคำว่า "ช้าง" "มี" "งวง" มาเรียงเป็น "ช้างมีงวง") เมื่อประโยคถูกต้องจรวดจะพุ่งทะยานขึ้นจอ ระบบให้คะแนนทันทีเมื่อผ่านด่าน

3.3 ครูฉายกระดานคะแนนรวม (Leaderboard) ขึ้นบนโปรเจกเตอร์เป็นระยะเพื่อสร้างแรงจูงใจ พร้อมดูรายละเอียดผ่าน Teacher Dashboard หากพบนักเรียนคะแนนต่ำกว่าเกณฑ์ให้เข้าไปให้คำแนะนำเป็นรายบุคคลทันที

### ขั้นที่ 4 ต่อยอดจากผลเกม (15 นาที)

4.1 ครูแบ่งนักเรียนเป็นกลุ่มย่อย กลุ่มละ 3-4 คน แจกกระดาษ A4 และปากกาเมจิก

4.2 กิจกรรม "แกลเลอรี่ประโยคแม่กง": แต่ละกลุ่มช่วยกันเลือกคำมาตราแม่กงที่พบในหน้าจอเกมมาแต่งเป็นประโยคที่กลุ่มชอบที่สุด เขียนด้วยลายมือของกลุ่มลงบนกระดาษ A4 ตัวโตอ่านง่าย แล้วนำไปติดบนกระดาน/ผนังห้องเรียน

4.3 นักเรียนเดินชมประโยคของเพื่อนรอบห้อง (Gallery Walk) แปะสติกเกอร์ดาวให้ประโยคที่ชอบที่สุด พร้อมให้ตัวแทนแต่ละกลุ่มยืนอ่านออกเสียงประโยคของกลุ่มตนเองให้เพื่อนฟัง ครูตรวจสอบความถูกต้องและช่วยแก้ไขทันทีหากมีคำหรือประโยคผิด

### ขั้นที่ 5 สรุป สะท้อนผล และประเมินผลการเรียนรู้ (10 นาที)

5.1 ครูใช้คำถามนำร่วมกับนักเรียนสรุปบทเรียนว่า **มาตราแม่กง คือ คำที่มี ง เป็นตัวสะกด และสามารถนำมาเรียงเป็นประโยคสื่อความหมายได้**

5.2 นักเรียนทำแบบทดสอบท้ายบทเรียน (Exit Ticket) จำนวน 5 ข้อ ผ่านหน้าจอ Web Application ของตนเอง เมื่อตอบถูกครบตามเกณฑ์ (อย่างน้อย 3 ใน 5 ข้อ) ระบบมอบสติกเกอร์ดาวดิจิทัลเป็นรางวัลบนหน้าจอ จากนั้นครูฉายกระดานคะแนนรวมและเหรียญรางวัลสรุปท้ายคาบขึ้นบนโปรเจกเตอร์

5.3 ครูแจกใบงานที่ 2 เรื่อง มาตราแม่กง ให้นักเรียนนำไปทำเพื่อทบทวนการจำแนกคำและการแต่งประโยค พร้อมแจ้งกำหนดส่ง

## 9. สื่อและแหล่งเรียนรู้

- Web Application เกมมาตราตัวสะกด ด่าน แม่กง (ใช้ทั้งโหมด Presentation นำเสนอเนื้อหา และโหมด Game ทำภารกิจ)
- อุปกรณ์สำหรับนักเรียน สัญญาณ Wi-Fi และโปรเจกเตอร์
- ระบบ Teacher Dashboard สำหรับครูผู้สอน
- กระดาษ A4 และปากกาเมจิก สำหรับกิจกรรมกลุ่ม "แกลเลอรี่ประโยคแม่กง"
- สติกเกอร์ดาว และใบงานที่ 2

## 10. การวัดและประเมินผล

- **K:** ตรวจคำตอบจาก Exit Ticket บน Web Application (ตอบถูกไม่น้อยกว่า 2 ใน 3 ข้อ)
- **P:** ตรวจคะแนนและผลการผ่านภารกิจ "กล่องคำแม่กง" และ "จรวดประโยคพุ่งทะยาน" บน Web Application (ผ่านร้อยละ 80), ประเมินการอ่านออกเสียงและการแต่งประโยคจากกิจกรรม "แกลเลอรี่ประโยคแม่กง"
- **A:** สังเกตพฤติกรรมการมีส่วนร่วมตลอดคาบเรียน (การร่วมเล่นเกมด้วยความตั้งใจ การให้ความร่วมมือในกลุ่ม) ผ่านเกณฑ์ระดับ "ดี" ขึ้นไป

## สรุปการปรับปรุงจากฉบับก่อนหน้า

1. ตัดแบบฟอร์มลงนามผู้บริหาร (ข้อ 11-15) ออก เหลือเฉพาะลงชื่อผู้สอนท้ายแผน
2. ปรับโครงสร้างเวลาเป็น **5+5+25+15+10** รวม 60 นาที ให้ตรงกับแผนฉบับใช้งาน
3. เปลี่ยนกิจกรรม "จัดกลุ่มคำด้วยบัตรคำ" (ขั้นที่ 3.2 เดิม ที่ใช้บัตรคำจับต้องจริง) เป็นภารกิจดิจิทัล **"กล่องคำแม่กง"** บนหน้าจอ Web Application เพื่อให้สื่อทั้งหมดเป็นดิจิทัล 100% ไม่มีบัตรคำอีกต่อไป
4. รวมภารกิจในขั้นที่ 3 เหลือ **2 ภารกิจ** (กล่องคำแม่กง 10 นาที + จรวดประโยคพุ่งทะยาน 15 นาที) รวมเวลา 25 นาที
5. รวมกิจกรรม "บันทึกนักสำรวจอวกาศ" (คัดลายมือ) กับ "แกลเลอรี่ประโยคแม่กง" เป็นกิจกรรมเดียวในขั้นที่ 4 (15 นาที) โดยย้ายการคัดลายมือไปเป็นส่วนหนึ่งของใบงานที่ 2
6. เปลี่ยน Exit Ticket ให้เป็นกระดาษคำตอบชัดเจน (เดิมก็เป็นกระดาษอยู่แล้ว คงรูปแบบเดิมไว้)
7. ปรับถ้อยคำจุดประสงค์ A จาก "มีความกระตือรือร้น สนุกสนาน และมีส่วนร่วมในกิจกรรมมินิเกม" เป็น "กล้าคิด กล้าตอบ ให้ความร่วมมือในการทำงานกลุ่ม และมีความกระตือรือร้นในการเล่นเกม" ให้สอดคล้องกับกิจกรรมกลุ่มและรูปแบบถ้อยคำที่ใช้ในแผนที่ 5-8
8. ตัด "บัตรคำ (Word Cards)" และ "สมุดบันทึกส่วนตัว/กระดานไวท์บอร์ด" ออกจากสื่อ (ข้อ 9) ให้เหลือเฉพาะสื่อที่ใช้จริงในโครงสร้างใหม่
